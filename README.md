## Structure

| Directory | Chapter | Topic |
|-----------|---------|-------|
| ch04-plugins-operators/ | Chapter 4 | Plugins, Services and Operators |
| ch05-streaming/ | Chapter 5 | Streaming and the Streamer Component |
| ch06-task-system/ | Chapter 6 | The OpenServerless Task System |

| ch11-development-workflow/ | Chapter 11 | Development Workflow |
| ch12-security/ | Chapter 12 | Security |
| ch13-services-spark/ | Chapter 13 | Services and the Spark Operator |

## Requirements

- Apache OpenServerless 0.1.0+
- ops CLI: https://github.com/apache/openserverless
- kubectl + MicroK8s or any Kubernetes cluster

## Notes

All examples have been tested on OpenServerless 0.1.0-incubating on MicroK8s/Multipass (Hetzner).
